# BGMフォルダ

ここに音楽ファイル（`.mp3` / `.m4a` / `.ogg` / `.wav`）を置いてpushすると、
サイトの📻再生時に**ランダムで1曲が小音量（15%）でループ再生**されます。

- ファイル名は自由（例: `lofi-morning.mp3`）
- 複数入れると再生のたびにランダムで選ばれます
- このフォルダが空の場合は、自動生成のコードBGMが流れます

⚠️ このリポジトリはpublicのため、ここに置いた音源は誰でもダウンロードできる状態になります。
市販曲や配布禁止の音源は置かず、フリーBGM（DOVA-SYNDROME、甘茶の音楽工房など）や
自作曲を使ってください。
