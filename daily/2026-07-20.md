## 🟡 ゲーム開発 × AI
### Rest of World「AIがゲーム開発チームを1人に縮小している」— トルコ発の実例レポート
- 情報源: https://restofworld.org/2026/ai-video-games-developer-jobs/
- 要約: AIツールによりソロ開発者が1人でゲームを完成させられるようになった一方、ジュニアのプログラマー・アーティスト・ライターの雇用が急減している実態をトルコのゲーム業界を例に報告。Claude Code・Copilot・Codexなどを使い「2年前は1人でゲームを作れるとは想像もできなかった」開発者が実際に完成まで到達している。
- 要約: 一方でトルコのゲームスタートアップは2021年の約200社から2024年に30社まで減少。参入障壁が下がった分だけ競争は激化し、利益が出るタイトルは全体の約2割にとどまるという指摘も。
- **活用ポイント:** Roblox個人開発はまさにこの「AIでソロ完結」の型。コーディングをClaude Code等に任せて、自分は企画・レベルデザイン・運営に集中する分業を意識的に組むと生産性の差が出る。

## 🟢 周辺技術（3Dモデル生成など）
### NVIDIA、SIGGRAPH 2026基調講演でニューラルレンダリング・世界モデル・エージェントAIを一挙発表
- 情報源: https://blogs.nvidia.com/blog/siggraph-news-2026/
- 要約: 7月20日のSIGGRAPH 2026（ロサンゼルス、7/19〜23開催）キーノートで、NVIDIAが3Dガイド付きニューラルレンダリング（アーティストの意図保持・時間的安定性・4Kリアルタイム描画）、エッジ向け4BパラメータのCosmos 3 Edge世界モデルなどを発表。
- 要約: BlenderやUnreal Engine、Houdini、Adobe Creative CloudなどのクリエイティブツールがMCP接続に対応し、AIエージェントが人間の制御下でアプリ内作業を行える構成を提示。キャラクターアニメーション向けのリアルタイムモーションモデル「MotionBricks」も公開された。
- **活用ポイント:** 「制作ツール側がMCPでエージェントに開かれていく」流れはRoblox Studio公式MCPと同じ方向。Blender+MCPでアセットを作ってStudioへ持ち込むパイプラインは今後さらに組みやすくなる。

### GitHub Code Quality が一般提供開始 — AI検出+Copilot Autofixでコード品質を自動改善
- 情報源: https://github.blog/changelog/2026-07-20-github-code-quality-is-now-generally-available
- 要約: CodeQLの静的解析とAI検出を組み合わせ、プルリクエストの保守性・信頼性の問題を検出するGitHub Code Qualityが7月20日にGA。Copilot Autofixがマージ前に修正案を提示し、組織全体の品質ダッシュボードやカバレッジ閾値によるクオリティゲートも備える。
- 要約: 料金はアクティブコミッター1人あたり月額10ドル+AI機能の従量課金。GitHub社内ではCode Quality指摘の67.3%がマージ前に解決されたという。
- **活用ポイント:** RojoなどでLuauコードをGitHub管理しているRobloxプロジェクトなら、AI生成コードが増えるほど「マージ前に機械が品質を見る」仕組みの価値が上がる。個人開発でもPRベース運用+自動レビューの型は真似できる。
