### Capcom、RE Engineを「AI-generation game engine」へ段階的に進化させる計画「REX」を発表

- 要約: Capcomは10月2日、東京で開催した「Capcom Open Conference RE:2026」で、自社ゲームエンジン「RE Engine」をAI活用に向けて段階的に進化させる長期計画「REX」を発表した。複数の独立報道が内容を一致させている。
- 要約: REXはRE Engineに組み込む複数のAI・機械学習プログラム群で、異なる形式のデータを共通ルールに変換して処理を高速化する「RE:Dox」などが含まれる。将来的にはAIがプログラムの意図を理解して自動生成したり、テストプレイで不具合を自動検出したりできるようにする狙いとされる。
- 要約: Capcomは「AIは開発者を助けるためのもので、プレイヤー向けのアートを作るためではない」と明言しており、グラフィック・音楽・ゲーム内の台詞は引き続き人間が作るとしている。発売日や具体的な対応タイトルは未発表。
- **活用ポイント:** 直接Robloxで使える技術ではないが、「AIにコード生成やテスト自動化を任せる一方、プレイヤーが直接触れるアート・音楽・台詞は人間が作る」という線引きは、個人・小規模チームがRoblox開発でAIの使い所を切り分ける際の判断基準として参考になる。

### 📚 テクニック: Roblox Assistantに自分のAPIキーを設定してプロバイダーを選ぶ「Manage API Keys」
- 情報源: https://create.roblox.com/docs/ai/accelerated-workflows（検索結果に引用された公式ドキュメントのスニペットで確認） / https://devforum.roblox.com/t/custom-providers-in-the-assistant/4744320 / https://devforum.roblox.com/t/add-more-free-ai-providers-for-studio-assistant/4728988
- 要約: Roblox公式ドキュメントによると、AssistantパネルからAPIキーを管理する「Manage API Keys」機能があり、Anthropic・OpenAI・Googleのいずれかの自分のAPIキーを設定して、使用するモデルをRoblox既定のものから切り替えられる。
- 要約: DevForumの開発者からの要望スレッドでは、現状この3プロバイダー以外（DeepInfra等のOpenAI互換エンドポイントやローカルモデル、NVIDIA NIM・OpenRouterのような無料枠のあるプロバイダー）には対応しておらず、多くの対応プロバイダーはAPI利用料が別途必要になる点が課題として挙がっている。
- **活用ポイント:** 既にAnthropic・OpenAI・Googleいずれかの有料APIキーを持っているチームは、RobloxデフォルトのAssistantモデルではなく使い慣れた/高性能なモデルに切り替えて使える。一方でローカルLLMや無料枠プロバイダーには未対応なため、コストを抑えたい個人開発者は現状の制約を踏まえて導入を検討するとよい。
